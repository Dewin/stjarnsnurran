# Stjärnsnurran ⭐🐻

En interaktiv, digital version av den klassiska elektroniska stjärntärningen från *Rupert Björn* (Rupert Bear) för barn- och sällskapsspel.

## Funktioner
- 🐻 **Autentisk leksaksdesign**: Röd nallebjörnsform, gul innerram, 3D-knapp och LED-effekter.
- ⭐ **6 stjärnor**:
  - Regnbåge (Joker / Valfri färg)
  - Gul
  - Blå
  - Orange
  - Grön
  - Lila
- 🔊 **Web Audio API**: Äkta retro elektroniska "blipp"-ljud, retardation och glad vinstfanfar.
- 🗣️ **Röstuppläsning**: Läser automatiskt upp vinnande färg på svenska via Web Speech API.
- 📳 **Haptisk feedback**: Vibrerar i telefonen i takt med snurrandet.
- 📱 **Progressive Web App (PWA)**: Installeras direkt på Android-telefonens startskärm som en fullskärmsapp.
- 🤖 **Android Studio Projekt**: Native Android-wrapper i `android/` redo att kompileras till `.apk`.
